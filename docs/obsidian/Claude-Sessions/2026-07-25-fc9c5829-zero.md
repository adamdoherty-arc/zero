## Key Lesson

**A critic reviewing a silently-truncated artifact will confidently reject for
"the implementation is missing."** Review 40 rejected this run's work listing
criteria that were all implemented and tested — it simply never saw those files.
The harness manufactured the verdict. Never hand a judge a partial artifact
without telling it the artifact is partial; and always include the test file in
`files_changed`.

Corollary found the same way: `str(httpx.ReadTimeout())` is the empty string, so
any handler formatting only `{e}` logs a blank error for the most common LLM
failure mode there is.
