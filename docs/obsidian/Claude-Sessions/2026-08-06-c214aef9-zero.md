## Key Lesson

A marker inside a string literal is not a marker, and a schema that declares a
list must yield a list. Both are boundary problems: a scanner that regexes raw
lines will eventually file its own fixtures as work, and a client that returns
whatever shape the model chose will silently lose every single-result reply.
Normalise at the boundary, once — not at each of eight call sites.
